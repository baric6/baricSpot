Some things to stay aware of:

* Make sure if you are going to do a forwarder or make it available on the network make sure to open the ports 8089 and 8000 on the machine you installed on
* From the splunk download page you can download the wget on a machine you are not signed in on. You can grab the wget on a faster machine an use the wget on another machine&#x20;

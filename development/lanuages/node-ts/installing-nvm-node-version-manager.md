# Installing (nvm) Node Version Manager

This is for quick switching and installing node versions great for compatibility

{% embed url="https://github.com/coreybutler/nvm-windows" %}

Go to the Github and click download stable&#x20;

```
nvm-setup.exe
```

When executing it leave everything default

To check if it is installed (make sure to open a new terminal window)

```
nvm -v
```

To install a node version (version 22 if you want 18 replace the number at the end)

```
nvm install 22
```

List versions you have

```
nvm list
```

Change or use a version

```
nvm use 22 or nvm 22.22.3
```

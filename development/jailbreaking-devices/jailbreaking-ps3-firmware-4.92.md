On the ps3

1. Disable auto updates
2. Disable "whats new"
3. Make sure date and time is correct
4. Get Web browser ready
   1. Set "confirm browser close" to off
   2. Set homepage to blank page &#x20;
   3. Delete cookies
   4. Delete search history&#x20;
   5. Delete Cache
   6. Delete Authentication history
5. Run exploit in browser
   1. Go to [https://www.ps3toolset.com/bgtoolset/](https://www.ps3toolset.com/bgtoolset/) and let it run it will take a second and you may only see a white screen but just wait it out sooner or later it will load. it took like 20s for mine to load
   2. When it loads it will auto exploit, accept any plugins that you get prompt for or it will fail
   3. It will be done when you see a popup with QR codes and a close button
6. (Not necessary) after the exploit finishes go to the top and select the tab called "System Manger". The selection called "Flash Memory" will allow you to save a .bin file to your usb
7. Patching firmware&#x20;
   1. Under "System Manager" you will see a option called "Flash Memory Patch" click on it and a drop down will appear.
   2. Select "Load Patch via HTTP" and let it download
   3. After it is done loading under "Flash Memory Patch" a new option is available "Apply Loaded Patch" click it and let it do its thing
   4. Close the browser
8. Reboot your ps3 to activate the patch
9. &#x20; Updating to homebrew firmware
   1. Make sure you have the ps3 folder on the usb and it is plugged in and able to be read
   2. When the ps3 comes back up, go to the system update it should give you the option to load update via a usb.
   3. Select usb and it should find the update named "4.92 Evilnat".&#x20;
   4. When the legal pager comes up scroll to bottom and push right to except it
   5. It will update like any other update&#x20;
10. The machine should restart&#x20;
11. When it comes back up go to the game selection and look for "Packet Manager" if you see this you are now jailbroken

The Packet Manager is a homebrew apploader that we will be using to install .pkg files in part 2.

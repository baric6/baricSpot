# Deskreen CE (Community Edition)

<figure><img src="../../.gitbook/assets/image (473).png" alt=""><figcaption></figcaption></figure>

Deskreen is an `electron.js` based application that uses `WebRTC` to make a live stream of your computer screen to a web browser on any device. It is available for MacOS, Windows and Linux operating systems. The current open-source Community Edition version has limited features. If you need more features please consider upgrading to [Pro](https://deskreen.com/download) version for more features when it is released.
